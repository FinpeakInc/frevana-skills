# ChatGPT Ads coverage audit

Verified on 2026-11-23 against the official Ads OpenAPI 2.3.0 download. The specification has **88 operations across 73 paths**. Each HTTP method and path maps to one skill operation. The CLI also exposes five advertiser endpoints documented in guides, conversion-event ingestion and SFTP file transfer. This gives **95 named operations**, comprising 42 reads and 53 operations requiring a saved proposal. The local draft card preview, standard launch and local Pixel helpers are additional workflows. [Official OpenAPI contract](https://developers.openai.com/ads/openapi.json) · [Local operation catalog](operations.json)

| Area | Implemented scope |
| --- | --- |
| Campaigns and creative | Search/list/read campaigns, groups and ads; create under new or existing parents; edit budget, schedule, targeting, links, bids and creative; pause, activate and archive individual resources; native submitted-ad preview. Daily and lifetime budgets, clicks, impressions and eligible conversion strategies, remote and binary images, single- and multi-image cards. |
| Bulk | Validation and execution jobs, idempotent submission, job status and per-operation results, forward pagination and partial-failure evidence. Bulk access is a limited preview. [Bulk API](https://developers.openai.com/ads/bulk-api) |
| Targeting and audiences | Geographic lookup and inclusion/exclusion, platform settings, context hints, customer-list uploads, audience creation, membership add/remove/replace/merge, inspection, operation status/resume/cancel, archive, inclusion/exclusion and bid multipliers. |
| Feeds and commerce | Product and eligible Hotel feeds, SFTP provisioning/rotation/pause/activation and confirmed catalog uploads, upload history, feed settings, product deltas and archive, item/product queries and review decisions, product/Hotel sets, dynamic templates, native previews and Hotel insights. The ad account must be enrolled for Hotel access. [Product feeds](https://developers.openai.com/ads/product-feeds) · [Hotel feeds](https://developers.openai.com/ads/hotel-feeds) |
| Measurement | Create/list web pixels and conversion event settings, issue a dedicated CAPI key, generate single- or multi-Pixel JavaScript and install the documented image fallback. Inspect recent events, validate or submit event batches with stable IDs, and query attributed events, sales and native ROAS. Deploying snippets and connecting them to real orders require access to the merchant site. [Conversions API](https://developers.openai.com/ads/conversions-api) |
| Reporting and diagnosis | Account, campaign, group and ad Insights with native fields, filters, sorting, breakdowns, zero-row options, attribution settings, hourly/daily/monthly/period granularity as supported, Hotel reports, crawler evidence, serving issues, low-bid diagnostics and eligible partners' sandbox evaluation jobs. |
| Administration | Account identification, listing and selection, partner identity and hosted onboarding sessions, account key issuance, brand changes, account activation/pause, dated and daily spend limits, and audit queries. The partner flow accepts an already issued OAuth access token or partner credential. |
| Lead Sync | Create and list account webhook subscriptions, get a subscription by ID, and delete an approved subscription. Signed webhook secrets stay in the private output. |
| Partner Data | Request an identity-graph Parquet upload session and get its status by ID. The creating operation returns private signed transfer instructions. File transfer is a separate step. |

Member invitations, billing/payment, tax, identity verification and partner credential issuance involve OpenAI-hosted or partner setup. The reviewed Ads specification did not identify public member-management or payment endpoints. The skill does not implement an OAuth client consent/refresh service. API enablement, scopes, account-specific validation, ad reviews and asynchronous ingestion are determined by OpenAI. Agent App UI and cross-channel CPA are outside this skill.

To repeat the comparison, download the official OpenAPI JSON and run `python3 -B skills/chatgpt-ads/tests/check_openapi.py /path/to/openapi.json` from the repository root. The check compares CLI commands against method/path pairs, path and query parameters, top-level request fields, required inputs and declared idempotency headers.

Offline tests cover request construction, CLI dispatch with mocked transport, approval binding, drift, retry behavior, data boundaries, and pagination. Runtime account permissions, real event attribution, live feed ingestion and delivery require an authorized account.
